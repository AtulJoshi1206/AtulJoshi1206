## Selected work

**[GridLock-VioScan](https://github.com/AtulJoshi1206/GridLock-VioScan)** — Traffic violation intelligence system. YOLOv8 + Gemini Vision detect violations, compute a severity index (VSI), automate fine waivers, and manage evidence logs end-to-end.

**[IncidentOps-Agentic-SRE](https://github.com/AtulJoshi1206/IncidentOps-Agentic-SRE)** — Production-grade agentic benchmark for SRE incident response. Evaluates LLM triage, diagnosis, and remediation in SaaS environments via the OpenEnv spec.

**[sentinel-os-agentic-benchmark](https://github.com/AtulJoshi1206/sentinel-os-agentic-benchmark)** — OpenEnv benchmark for LLM agents diagnosing hidden system failures, with trajectory-based scoring of recovery efficiency.

**[AI-Autonomous-Farming-Operator](https://github.com/AtulJoshi1206/AI-Autonomous-Farming-Operator)** — Multi-agent decision engine that authorizes real farm operations (planting, irrigation, fertigation). Deterministic, LLM-free safety pipeline underneath a conversational layer (EN/HI); the system commits and verifies actions rather than just advising.

**[Dodge-AI-FDE](https://github.com/AtulJoshi1206/Dodge-AI-FDE)** — Graph-based O2C query system for SAP data. LLM acts as a strict router over a deterministic graph traversal layer — no hallucinated numbers in a finance context.

**[MindScript-team](https://github.com/AtulJoshi1206/MindScript-team)** — AI mental-wellness companion: React + FastAPI + Gemini 2.5, conversational mood tracking.

**[supportops-env](https://github.com/AtulJoshi1206/supportops-env)** — Agentic benchmark (OpenEnv RL Challenge) simulating a support-ops center where an AI coordinator triages tickets and holds SLOs.
